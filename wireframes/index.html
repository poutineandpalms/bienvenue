Bienvenue v3 — Wireframes

Low fidelity on purpose: boxes, labels, and focus states only — no colours, no final art. The goal is to test structure and scale: can this layout hold every feature we listed without becoming a settings page? Built as live HTML so the winning frames can evolve into the real app.

How to read: the thick black tile marked FOCUS is where the remote cursor sits. Dashed border inside each TV = the TV-safe area (nothing important outside it). Grey tiles = features that only appear when relevant. Every tile is either an action (does something) or a deep link (opens a phone page) — no decorative clutter.

TV — BIENVENUE APP (primary)

Big-screen home for the visit: greeting, sections, room controls, folio summary. Everything works with the remote; the core works offline.

⇄

HOST — ALEX + MAPLE (behind the scenes)

Visit profiles, content updates, photo-of-the-day, Tricount refresh, flight tracking. Guests never see this; Alex mostly just talks to Maple.

→

PHONE — GUEST COMPANION (secondary)

One QR from the TV opens details: guide, itinerary, folio, room controls. No install required; a notification channel only if we decide it earns its place.
